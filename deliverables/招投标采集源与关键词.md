## 二、关键词（优化后 27 个，按优先级分层）

### ① 安全服务（核心 · 必查）— 10 个

等保测评、渗透测试、安全运维、安全服务、安全审计、应急响应、漏洞扫描、数据安全、网络安全、信息安全

### ② 安全产品 / 设备（重点 · 必查）— 8 个

防火墙、堡垒机、加密机、入侵检测、态势感知、终端安全、身份认证、安全设备

### ③ IT / 集成 / 硬件（补充 · 选查）— 9 个

系统集成、信息化、云平台、服务器、存储、网络设备、数据中心、安防监控、IT运维

## 三、关键词合并说明（对照原始 42 个）

| 合并后 | 原词 |
| --- | --- |
| 等保测评 | 等保测评 + 等级保护 + 等保 |
| 网络设备 | 网络设备 + 交换机 + 路由器 |
| 安防监控 | 安防 + 监控 + 弱电 |
| 数据中心 | 数据中心 + 机房 |
| 信息化 | 信息化 + 信息系统 |
| 安全设备 | 网络安全设备采购 |
| 网络安全 | 网络安全 + 网络安全建设 |
| 安全服务 | 安全服务 + 安全管理 + 安全防护 |

已删除的泛词 / 低相关词：技术服务、硬件采购、软件采购、数据库。

## 四、采集说明

- 优先用「①安全服务」和「②安全产品/设备」两层关键词 × 各采集源进行组合检索。
- 「③IT/集成/硬件」作为补充维度，覆盖集成类、硬件类项目。
- 云南地区为重点关注区域（云南省政府采购网、公共资源交易平台-云南）。
- 信息必须注明来源与时间，不得编造招标信息。
