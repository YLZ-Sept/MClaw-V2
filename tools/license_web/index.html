MClaw 授权码签发

离线工具 · 私钥不上传、不保存，关闭页面即清除

1加载签发私钥

选择 private.pem（默认在 E:\mclaw-license-keys\）。每次打开页面都要重新选一次。

2填写授权信息

会显示在客户的激活成功页上，请填正式公司名。
客户在激活页点「复制」发给你的 5 段码。粘贴后会自动校验。
0 = 不限
留空按本机台账自动递增（MC-年份-序号）。

3授权码已生成

把这串码发给客户，粘贴到激活页即可。此码只能在机器码对应的那台机器上激活。

4签发台账

台账存在这台电脑的浏览器里。请定期导出 CSV 汇总到 E:\mclaw-license-keys\license_ledger.csv， 否则换电脑、清缓存会丢记录。
